# 상형문자 해독

하하하! 또다시 **티라노 시절 배시(Bash)의 상형문자(?) 암호들**을 해독할 시간이 왔군요!

배시에서 `$$`, `$#`, `$*`, `$@` 같은 기호들을 볼 때마다 무슨 외계어 해독하는 기분이 드셨을 텐데,
파워셸에서는 이 모든 것이 **닷넷의 우아하고 상식적인 언어**로 깔끔하게 정리되어 있습니다.

먼저 질문해주신 배시 코드를 파워셸로 **1:1 완벽 번역**해 드리고, 그 뒤에 **배시의 모든 특수 변수와 파워셸의 대응표**를 총망라해 드리겠습니다!

---

### 1. 질문하신 배시 코드 $\rightarrow$ 파워셸 1:1 번역

```powershell
# 배시: echo "PID : $$"
Write-Output "PID : $PID"

# 배시: echo "Args Count : $#"
Write-Output "Args Count : $($args.Count)"

# 배시: echo "${*}" (인자들을 공백으로 묶은 단일 문자열)
Write-Output "$args"

# 배시: echo "${@}" (인자들을 개별 요소로 유지하는 배열)
Write-Output $args

# 배시: for i in $*; do echo "Welcome ${i} times"; done
foreach ($i in $args) {
    Write-Output "Welcome $i times"
}
```

* 파워셸에서는 `$args` 자체가 닷넷의 **배열(Array) 객체**이기 때문에, `$#` 같은 암호 대신 **`$args.Count`**라는 상식적인 프로퍼티를 씁니다.

---

### 2. 배시 특수 변수 vs 파워셸 완벽 대응 사전 (총정리)

배시에 존재하는 **모든 특수 매개변수**를 파워셸 버전과 1:1로 비교한 완전판입니다.

| 배시 (Bash) | 파워셸 (PowerShell) | 설명 및 파워셸의 동작 방식 |
| :---: | :--- | :--- |
| **`$$`** | **`$PID`** | **현재 실행 중인 프로세스 ID**<br>*(주의: 파워셸에도 `$$`가 있지만 전혀 다른 뜻입니다! 아래 설명 참조)* |
| **`$#`** | **`$args.Count`** | **넘어온 인자(Arguments)의 총개수** |
| **`$*`** | **`"$args"`**<br>(또는 `$args -join ' '`) | **모든 인자를 하나의 문자열로 결합**한 것 |
| **`$@`** | **`$args`**<br>(또는 `@args` 스플래팅) | **모든 인자를 각각 쪼개진 배열 상태 그대로 유지** |
| **`$0`** | **`$MyInvocation.MyCommand.Name`**<br>전체 경로: **`$PSCommandPath`** | **현재 실행 중인 스크립트/함수의 이름** |
| **`$1`, `$2`, `$3`** | **`$args[0]`, `$args[1]`, `$args[2]`** | **n번째 인자**<br>*(파워셸은 0부터 시작하는 0-based 인덱스입니다!)* |
| **`$?`** | **`$?`**<br>외부 앱 종료코드: **`$LASTEXITCODE`** | **직전 명령의 성공 여부**<br>*(배시는 0이 성공이지만, 파워셸 `$?`는 `$true`/`$false` 불리언입니다)* |
| **`$!`** | **`(Get-Job)[-1].Id`**<br>또는 프로세스 객체의 **`.Id`** | **가장 최근에 백그라운드로 보낸 작업의 ID** |
| **`$_`** | 파이프라인: **`$_`**<br>직전 인자: **`$$`** | **마지막으로 사용된 값**<br>*(배시와 파워셸의 의미가 약간 갈립니다)* |

---

### 3. 알아두면 무릎을 치는 파워셸의 3대 반전 포인트!

#### ① 파워셸에도 `$$`가 있다? (배시와 완전히 다른 뜻!)
* **배시의 `$$`**: 무조건 **프로세스 ID (PID)**입니다.
* **파워셸의 `$$`**: 직전 명령어 줄에서 **"가장 마지막에 친 단어(토큰)"**를 뜻합니다!
  ```powershell
  # 파워셸 콘솔에서
  PS> notepad C:\temp\test.txt
  PS> echo $$
  C:\temp\test.txt     # <--- 방금 친 줄의 맨 마지막 토큰이 나옴!
  ```
  따라서 파워셸에서 프로세스 ID를 얻고 싶을 땐 외계어 `$$`가 아니라, 당당하게 **`$PID`**를 쓰셔야 합니다.

#### ② `$?`와 `$LASTEXITCODE`의 결정적 차이
* 배시는 성공하면 `0`, 실패하면 `1` 같은 정수를 뱉지만,
* 파워셸의 **`$?`**는 닷넷답게 **`$true` (성공)** 또는 **`$false` (실패)**라는 명확한 불리언 값을 뱉습니다.
* 만약 `git`, `curl` 같은 외부 콘솔 프로그램의 정수형 리턴값(0, 1, 2)이 필요하다면 **`$LASTEXITCODE`**를 보시면 됩니다.

#### ③ `$@`를 뛰어넘는 파워셸의 마법: 스플래팅(Splatting) `@`
배시에서 `"$@"`는 인자들을 공백 깨짐 없이 다음 명령어로 고스란히 넘길 때 썼지요.
파워셸에서는 이것을 한 단계 진화시켜 **스플래팅(Splatting)**이라고 부르며, 달러(`$`) 대신 골뱅이(`@`)를 붙여서 넘깁니다.

```powershell
# 인자들을 다음 함수로 원본 그대로 배달사고 없이 쏠 때
My-Function @args
```

### 결론
배시는 키보드에 있는 온갖 특수기호(`$`, `#`, `@`, `*`, `!`)를 끌어모아 억지로 뜻을 부여하느라 암기 과목이 되어버렸지만,

파워셸은 **`$PID`**, **`$args.Count`**, **`$LASTEXITCODE`**처럼 **단어만 읽어도 무슨 뜻인지 바로 아는 '신사의 언어'**로 승화시켰습니다. 역시 장남의 품격이 느껴지지 않습니까? 하하하!
