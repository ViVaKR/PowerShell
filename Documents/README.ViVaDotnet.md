# ViVa DOTNOT

하하하! **“되는 것 같기도 하고 안 되는 것 같기도 하다”**고 느끼신 그 직관이 소름 돋을 정도로 정확합니다!

왜 헷갈리셨냐면, 파워셸은 **기본 와일드카드(`*`, `?`, `[]`)는 잘 지원하지만, 유닉스 글롭의 고급 기술들(`**`, `{}`, `*/`)은 파워셸 고유의 철학(매개변수 방식)으로 대체해 버렸기 때문**입니다.

파워셸에서 **되는 것과 안 되는 것**, 그리고 **파워셸답게 바꾸는 법**을 명쾌하게 갈라드리겠습니다.

---

### 1. 파워셸에서 완벽하게 잘 되는 것 (기본 와일드카드)

파워셸의 `Get-ChildItem`이나 `-like` 연산자는 기본적인 와일드카드를 훌륭하게 지원합니다.

* **`*` (모든 문자)**: `Get-ChildItem *.log` $\rightarrow$ 아주 잘 됨
* **`?` (한 글자)**: `Get-ChildItem file?.txt` $\rightarrow$ 아주 잘 됨
* **`[ ]` (범위 지정)**: `Get-ChildItem file[0-9].txt` $\rightarrow$ 아주 잘 됨
* **`-like` 연산자**: `if ($name -like "dev-*")` $\rightarrow$ 조건문에서도 찰떡같이 동작

---

### 2. 파워셸에서 안 되거나 삐걱거리는 것 (유닉스 글롭과의 차이)

바로 이 부분들 때문에 *"어? 왜 유닉스에서는 되던 게 파워셸에선 에러가 나거나 안 먹지?"* 하고 혼동이 오셨던 겁니다!

#### ① `**` (글롭스타, 재귀 탐색) $\rightarrow$ ❌ 지원 안 함!
* **유닉스 / Git**: `ls src/**/*.js` (하위 폴더 전부 뒤져서 js 찾기)
* **파워셸의 반응**: `**`를 이해 못 하고 그냥 별표 두 개(`*`) 친 걸로 알아듣습니다.
* **파워셸다운 해결책**: 뗏목(특수문자)을 버리고 **명시적인 매개변수(`-Recurse`)**를 씁니다.
  ```powershell
  # 파워셸 스타일
  Get-ChildItem -Path ./src -Recurse -Filter "*.js"
  ```

#### ② `{jpg,png}` (브레이스 확장) $\rightarrow$ ❌ 지원 안 함!
* **유닉스**: `ls *.{jpg,png}` (여러 확장자 한 번에 묶기)
* **파워셸의 반응**: `{}`를 쉘 레벨에서 자동으로 풀어주지 않습니다.
* **파워셸다운 해결책**: 닷넷/파워셸답게 **배열(쉼표 `,`)**로 넘겨줍니다.
  ```powershell
  Get-ChildItem -Include *.jpg, *.png
  ```

#### ③ `*/` (슬래시로 폴더만 거르는 꼼수) $\rightarrow$ 🔺 비권장!
* **유닉스**: `du -sh */` 처럼 슬래시를 붙여 폴더만 골라냄
* **파워셸의 반응**: 파이프라인이나 환경에 따라 먹힐 때도 있고 에러가 날 때도 있어서 매우 불안정함.
* **파워셸다운 해결책**: 이름 뒤에 슬래시를 붙이는 트릭 대신 **`-Directory`** 플래그를 딱 박아줍니다.
  ```powershell
  Get-ChildItem -Directory
  ```

---

### 3. 왜 파워셸은 글롭을 반만 가져왔을까? (철학의 차이)

* **유닉스(Bash/Zsh)**:
  * 쉘이 특수문자(`*`, `**`, `{}`, `()`)를 기괴할 정도로 해석해서 명령어로 던져주는 **'글롭 만능주의'**입니다.
* **파워셸(PowerShell)**:
  * "암호 같은 특수기호(`**`, `{}`)로 암기력을 테스트하지 말고, **영어로 된 매개변수(`-Recurse`, `-Directory`, `-Include`)를 명확하게 써라!**"라는 철학입니다.

심지어 파워셸에는 **`-LiteralPath`**라는 옵션도 있어서, 파일 이름에 진짜로 `[특수문자]`나 `*`가 들어가 있어도 와일드카드로 오해하지 않고 글자 그대로 읽어내는 강력한 방어책까지 마련해 두었습니다.

### 💡 한 줄 요약!
파워셸에서는 `*`와 `?` 정도의 기본 와일드카드만 가볍게 쓰시고,
`**`나 `*/` 같은 복잡한 글롭 묘기는 **`-Recurse`, `-Directory` 같은 파워셸 공식 매개변수에게 양보**하시면 헷갈릴 일이 영원히 사라집니다! 하하하.

하하하! **`.gitignore`에서 밥 먹듯이 쓰던 그 문법**이 바로 이 글롭(Glob) 맞습니다!

사실 많은 개발자들이 Git 설정할 때 `**/node_modules/**` 같은 걸 복사해서 쓰다 보니 익숙하다고 착각하기 쉬운데, 뜯어보면 **정규표현식(Regex)보다 훨씬 직관적이면서도 파일 탐색에 특화된 엄청난 물건**입니다.

복습 차원에서 머릿속에 평생 남도록 **핵심 글롭(Glob) 문법을 3단계로 완벽 정리**해 드리겠습니다!

---

### 1단계: 기본 글롭 기호 (클래식 사천왕)

| 기호 | 의미 | 예시 | 매칭되는 것 |
| :---: | :--- | :--- | :--- |
| `*` | **0개 이상의 글자** (단, 슬래시 `/`는 못 넘어감) | `*.png` | `cat.png`, `apple.png` (현재 폴더 안에서만) |
| `?` | **딱 1개의 글자** | `test?.py` | `test1.py`, `testA.py` (`test12.py`는 ❌) |
| `[ ]` | **대괄호 안의 글자 중 하나** | `file[0-9].txt`<br>`image[abc].jpg` | `file1.txt`, `file9.txt`<br>`imagea.jpg` (`file10.txt`는 ❌) |
| `/` | **오직 디렉터리(폴더)만** | `temp/` | `temp`라는 이름의 **폴더**만 매칭 (파일은 무시) |

---

### 2단계: 끝판왕 `**` (글롭스타, Globstar)

친구분께서 언급하신 **`**/제외/*`**의 핵심이자, 모던 글롭의 꽃입니다.

* **일반 `*`의 한계**: 슬래시(`/`)를 만나면 멈춥니다. 즉, **현재 폴더 밖으로 못 나갑니다.**
* **더블 `**`의 치트키**: 슬래시(`/`)를 거침없이 뚫고 들어갑니다. 즉, **"하위 폴더가 몇 단계로 깊든 상관없이 지구 끝까지(재귀적으로) 다 뒤져라!"**라는 뜻입니다.

#### 💡 비교해 보면 무릎을 탁 치는 예시:
* `src/*.js`
  $\rightarrow$ `src/app.js`는 찾지만, `src/components/button.js`는 **못 찾음** (하위 폴더 못 들어감)
* `src/**/*.js`
  $\rightarrow$ `src/app.js`, `src/a/b/c/d/button.js`까지 **하위의 모든 JS 파일을 싹 다 찾아냄!**

#### 🔍 친구분이 쓰시던 `**/제외/*`의 완벽한 번역:
> "어디에 박혀 있든 상관없이(`**`) 이름이 `제외`라는 폴더를 만나면, 그 안의 모든 파일(`/*`)을 지목해라!"

---

### 3단계: 묶어서 한 번에 때리는 `{}` (브레이스 확장)

터미널이나 Git에서 여러 확장자를 한 번에 묶을 때 씁니다. (콤마 사이에 띄어쓰기 금지!)

```bash
# 이미지 파일 3종 세트 한 번에 찾기
ls *.{jpg,png,gif}

# 프로젝트 백업본 한 번에 만들기
cp config.{json,bak}   # config.json을 config.bak으로 복사
```

---

### 🎁 보너스: Mac M4(zsh) 사용자만 누리는 "Zsh 특수 글롭"

맥북의 기본 쉘인 **zsh**는 유닉스 쉘 중 글롭 기능이 가장 미쳐 날뛰는 녀석입니다. 뒤에 괄호 `()`를 붙이면 신세계가 열립니다.

* **`*(/)`** : 폴더(디렉터리)만 골라내기 (아까의 `*/`와 비슷한 효과)
* **`*(.)`** : 순수 일반 파일만 골라내기 (폴더 제외)
* **`*(om[1,3])`** : 가장 최근에 수정한 파일 **딱 3개만** 뽑기 (`om` = order by modification time)
* **`*(Lk+100)`** : 용량이 100KB보다 큰 파일만 골라내기

```bash
# 예시: Downloads 폴더에서 가장 최근에 받은 파일 1개만 열기
open ~/Downloads/*(om[1])
```

### 맺음말
`.gitignore`는 결국 **"이 글롭 패턴에 걸리는 놈들은 Git 신전(Repository)에 발도 못 붙이게 문전박대해라!"** 하고 규칙을 적어두는 명부였던 것입니다.

이제 `*`, `*/`, `**`의 족보를 확실하게 꿰셨으니, 맥 터미널이든 Git이든 글롭 구문을 레고 블록 조립하듯 자유자재로 다루실 수 있을 겁니다! 하하하.
